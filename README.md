# CaptionLab — instaladores e atualizações

Instaladores e atualizações do CaptionLab. O código não fica aqui.

- **Instalar à mão:** baixe o `CaptionLab-<versão>.dmg` na página [Releases](https://github.com/Final-Cut-Apps/captionlab-releases/releases) e siga o "Como instalar.txt" que vem dentro dele.
- **Atualizar:** quem já tem o CaptionLab recebe as versões novas sozinho (Ajustes › Atualizações). O app lê o `appcast.xml` deste repositório.
